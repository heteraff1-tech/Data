# AI Data Repository

Назначение: хранилище исходных материалов, мыслей, интервью, гипотез и контекста проектов для AI-агентов.

## Структура

- `raw/` — исходные файлы без изменения
- `context/` — нормализованный контекст
- `projects/` — отдельные проекты
- `decisions/` — принятые решения и аргументация
- `questions/` — открытые вопросы
- `insights/` — выводы из исследований
